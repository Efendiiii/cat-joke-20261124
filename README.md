A single one-line cat joke, under 200 characters, for the [make.fun competition "The One-Line Cat Joke That Lands"](https://make.fun/competitions/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) ($2 winner-takes-all). `main.ts` (Node 22 stdlib-only) writes the joke to `/output/entry.txt`, guarded by a 1–200 character assertion.

## Run

```sh
node main.ts
cat /output/entry.txt
```
